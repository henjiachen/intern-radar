# Priority internship programs

Profile: UCSD freshman studying CS. Summer 2027, United States.
Missing graduation year is allowed; no original-author experience or
application restrictions apply.

| Target | How it is watched |
| --- | --- |
| Xbox / Microsoft | Community feeds; Explore titles recognized |
| PlayStation / Sony Interactive Entertainment | Public Greenhouse internship board plus community feeds |
| Nintendo | Public careers job cards and internship descriptions |
| NVIDIA | Workday plus community feeds |
| Google | Community feeds; STEP/ASDI names recognized |
| Salesforce | Workday plus community feeds |
| TikTok / ByteDance | Community feeds; no company exclusion |

Gaming targets receive earlier placement, not a relaxed eligibility rule.
Full descriptions can contain restrictions that titles leave out. The current
Nintendo multimedia internship, for example, states a rising-senior requirement;
that requirement is incompatible with this freshman profile.

Official program and job pages:
- [PlayStation emerging talent](https://careers.playstation.com/early-careers)
- [Nintendo jobs](https://careers.nintendo.com/jobs/)
- [Microsoft Explore](https://careers.microsoft.com/v2/global/en/exploremicrosoft)

These are monitoring targets, not a claim that every program currently has an
open freshman-eligible Summer 2027 role.
